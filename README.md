# The Poem About Permission

An entry for the make.fun bounty [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

The program (`main.ts`, Node 22) writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The poem is built around a single concrete image: a password written on a sticky note and pressed into the speaker's palm, access handed over by hand. The door opens at the speaker's touch, and the poem closes on the insight that trust is a lock that learned a second name.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

## Entry

```
You wrote the password on a sticky note
and pressed it into my palm.
Four digits. No ceremony.
The door opened at my touch
as if it had always known me —
trust is just a lock
that learned a second name.
```
